# Jyoti Ranjan Behera - Developer Portfolio

A modern, responsive, and animated personal portfolio website built with Next.js, React, Tailwind CSS, and Framer Motion.

## 🚀 Live Demo
------------------------- https://portfolio-jrb.vercel.app --------------------------

## ✨ Features
* **Modern UI/UX:** Clean, elegant design with glassmorphism effects and dark mode aesthetics.
* **Smooth Animations:** Integrated with Framer Motion for scroll-triggered reveal animations and page transitions.
* **Interactive Tech Stack:** Visual grid representation of Frontend, Backend, and DevOps skills.
* **Project Showcase:** Detailed project cards with live links and source code references.
* **Experience Timeline:** Professional educational and work experience timeline.
* **Resume Integration:** Dedicated resume preview and download section.
* **Fully Responsive:** Optimized for mobile, tablet, and desktop devices.

## 🛠️ Technology Stack
* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Library:** [React](https://reactjs.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Animations:** [Framer Motion](https://www.framer.com/motion/)
* **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
* **Typography:** [Geist Font Family](https://vercel.com/font)

## 💻 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Pupun45/Portfolio-on-Next.js.git
```

2. Navigate to the project directory:
```bash
cd Portfolio-on-Next.js
```

3. Install the dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser to see the portfolio.

## 📁 Project Structure

* `src/app`: Next.js App Router endpoints and pages (`/about`, `/projects`, `/skills`, `/experience`, `/resume`).
* `src/components`: Reusable UI components (Hero, Navbar, Skills, Footer, etc.).
* `src/data`: Static data structures for projects, skills, and experience details.
* `public`: Static assets including images, icons, and resume PDF.
